# Meeting follow-ups

Discover connected meeting-query and page-fetch tools. Verify the authenticated account and meeting ownership. Missing access is unavailable, not an empty result. No company-specific database or recorder name is assumed.

Read summaries only during refresh. Use edit times and exhaust pagination. Pending, truncated or missing summaries leave coverage partial. Exclude accidental recordings and content outside the actual meeting. If the recording boundary is unclear, keep only a neutral review link and explain the uncertainty.

Keep explicit commitments for the authenticated user, decisions needing follow-up and unresolved ownership. Suggestions and discussion questions are not commitments. Do not copy transcripts or sensitive personnel, health or family details into the queue.

For a separately selected integration, re-fetch only that meeting and verify the date, participants and existing filed entries. Use the explicitly configured notes directory. If none is configured, stop and ask for one. Propose exact file changes and check the configured Reminders list for duplicates. Wait for explicit confirmation before any file or reminder write. Never resolve the queue item automatically.
